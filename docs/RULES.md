Generated by `scripts/update_rule_docs.py`.

establish a browser failure, an SEO penalty, WCAG compliance, or security.

## SEO001 — Missing page title

Add a descriptive <title> to <head>.

[Primary reference](https://html.spec.whatwg.org/multipage/semantics.html#the-title-element)

## SEO002 — Title outside the suggested length

Review the title for clarity; 15–70 characters is only a heuristic, not a search-engine limit.

[Primary reference](https://developers.google.com/search/docs/appearance/title-link)

## SEO003 — Missing meta description

Add a concise, page-specific <meta name="description" content="...">.

[Primary reference](https://developers.google.com/search/docs/appearance/snippet)

## SEO004 — Missing canonical URL

Consider a <link rel="canonical" href="https://..."> when alternate URLs serve the same content.

[Primary reference](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls)

## SEO005 — Missing primary heading

Add an <h1> that describes the page's main topic.

[Primary reference](https://www.w3.org/WAI/WCAG22/Understanding/headings-and-labels.html)

## SEO006 — Multiple primary headings

Review the document outline; multiple h1 elements are not automatically invalid or an SEO penalty.

[Primary reference](https://html.spec.whatwg.org/multipage/sections.html#headings-and-outlines)

## A11Y001 — Missing document language

Set <html lang="en"> (or the actual language) to help assistive technology pronounce content.

[Primary reference](https://www.w3.org/WAI/WCAG22/Understanding/language-of-page.html)

## A11Y002 — Image has no alt attribute

Add meaningful alt text, or alt="" for a purely decorative image.

[Primary reference](https://www.w3.org/WAI/WCAG22/Understanding/non-text-content.html)

## A11Y003 — Button has no detected accessible name

Add visible button text, aria-label, or aria-labelledby pointing to descriptive text.

[Primary reference](https://www.w3.org/WAI/WCAG22/Understanding/name-role-value.html)

## A11Y004 — Link has no detected accessible name

Add descriptive link text or an equivalent accessible name.

[Primary reference](https://www.w3.org/WAI/WCAG22/Understanding/link-purpose-in-context.html)

## A11Y005 — Form control has no detected label

Associate a <label for="id"> with the control, wrap it in a label, or provide aria-labelledby/aria-label.

[Primary reference](https://www.w3.org/WAI/WCAG22/Understanding/labels-or-instructions.html)

## A11Y006 — Skipped heading level

Review the heading hierarchy; a jump can make the page harder to navigate.

[Primary reference](https://www.w3.org/WAI/tutorials/page-structure/headings/)

## HTML001 — Duplicate element ID

Make IDs unique and update labels, fragments, and ARIA references that point to them.

[Primary reference](https://html.spec.whatwg.org/multipage/dom.html#the-id-attribute)

## HTML002 — Missing responsive viewport

Add <meta name="viewport" content="width=device-width, initial-scale=1">.

[Primary reference](https://developer.mozilla.org/en-US/docs/Web/HTML/Viewport_meta_tag)

## PERF001 — Image dimensions are not declared in HTML

Add width and height, or reserve aspect-ratio in CSS. This check cannot inspect external CSS.

[Primary reference](https://web.dev/articles/optimize-cls)

## PERF002 — Potentially blocking script in head

Use defer or async when safe, a module script, or move the script after the content.

[Primary reference](https://html.spec.whatwg.org/multipage/scripting.html#the-script-element)

## PERF003 — Large HTML document

Review duplicated markup and inline payloads; the 200 KiB threshold is an advisory budget.

[Primary reference](https://web.dev/articles/reduce-network-payloads-using-text-compression)

## SEC001 — Page delivered over HTTP

Serve the page over HTTPS and redirect HTTP requests to HTTPS.

[Primary reference](https://developer.mozilla.org/en-US/docs/Web/Security/Transport_Layer_Security)

## SEC002 — HTTP resource on an HTTPS page

Replace the insecure embedded resource URL with HTTPS or a same-origin relative URL.

[Primary reference](https://developer.mozilla.org/en-US/docs/Web/Security/Mixed_content)

## SEC003 — Form submits over HTTP

Deliver the page and submit the form over HTTPS.

[Primary reference](https://html.spec.whatwg.org/multipage/forms.html#attr-fs-action)

## SEC004 — No enforced Content Security Policy detected

Deploy a tested Content-Security-Policy HTTP header. Presence alone does not prove a safe policy.

[Primary reference](https://developer.mozilla.org/en-US/docs/Web/HTTP/Headers/Content-Security-Policy)

## SEC005 — Missing MIME sniffing protection

Return the HTTP header X-Content-Type-Options: nosniff.

[Primary reference](https://developer.mozilla.org/en-US/docs/Web/HTTP/Headers/X-Content-Type-Options)

## SEC006 — No positive HSTS max-age detected

After verifying HTTPS everywhere, send Strict-Transport-Security with a positive max-age.

[Primary reference](https://developer.mozilla.org/en-US/docs/Web/HTTP/Headers/Strict-Transport-Security)

## SEC007 — No framing restriction detected

Set an appropriate CSP frame-ancestors directive or X-Frame-Options: DENY/SAMEORIGIN.

[Primary reference](https://developer.mozilla.org/en-US/docs/Web/HTTP/Headers/Content-Security-Policy/frame-ancestors)
